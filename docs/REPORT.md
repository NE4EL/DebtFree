## 1. Введение

### 1.1. Актуальность

Пользователи часто имеют несколько кредитов и долгов одновременно: кредитную карту, потребительский кредит, рассрочку. Ставки, остатки и минимальные платежи у них разные, поэтому не очевидно, в каком порядке выгоднее гасить долги и сколько в итоге придётся переплатить. Приложение DebtFree автоматизирует эти расчёты и позволяет наглядно сравнить варианты.

### 1.2. Цель

Разработать веб-приложение для планирования погашения долгов, которое рассчитывает платежи, сравнивает стратегии погашения и оценивает переплату.

### 1.3. Задачи

1. Спроектировать модель данных и пользовательские сценарии.
2. Реализовать расчёт аннуитетных и дифференцированных платежей.
3. Реализовать моделирование стратегий погашения («Лавина», «Снежный ком», базовая).
4. Реализовать расчёт общей переплаты и сценарии досрочного погашения.
5. Реализовать визуализацию графика остатка долга.
6. Покрыть расчётный модуль unit-тестами.

## 2. Анализ предметной области

### 2.1. Основные понятия

| Термин | Определение |
|--------|-------------|
| Остаток долга (тело долга) | Сумма, которую ещё нужно вернуть без учёта процентов |
| Годовая ставка | Процент, начисляемый на остаток за год |
| Аннуитетный платёж | Равный ежемесячный платёж; доля процентов в начале больше |
| Дифференцированный платёж | Основной долг гасится равными частями, проценты считаются на остаток, платёж уменьшается со временем |
| Переплата | Разница между общей суммой выплат и первоначальной суммой долга |
| Досрочное погашение | Платёж сверх графика, который уменьшает остаток |

### 2.2. Стратегии погашения

| Стратегия | Правило | Особенность |
|-----------|---------|-------------|
| Лавина (Avalanche) | Свободные деньги направляются на долг с **наибольшей ставкой** | Обычно минимальная переплата |
| Снежный ком (Snowball) | Свободные деньги направляются на долг с **наименьшим остатком** | Быстрее закрываются отдельные долги, психологически проще |
| Базовая (только минимальные) | Каждый долг гасится своим минимальным платежом, без перераспределения | Используется как точка сравнения |

### 2.3. Существующие решения

Для расчёта кредитов используются банковские калькуляторы и электронные таблицы. Их типичный недостаток: рассматривается один кредит, а сравнение стратегий по нескольким долгам требует ручной настройки. DebtFree ориентирован именно на несколько долгов и сравнение стратегий.

## 4. Бизнес-логика

Обозначения: S — остаток долга, r — годовая ставка (%), i = r / 12 / 100 — месячная ставка, n — число месяцев.

### 4.1. Аннуитетный платёж

```text
A = S · i / (1 − (1 + i)^(−n)),    при i = 0:  A = S / n
```

Для месяца k: проценты `P_k = B_{k−1} · i`, основной долг `D_k = A − P_k`, остаток `B_k = B_{k−1} − D_k`.

### 4.2. Дифференцированный платёж

```text
D = S / n                       (основной долг, постоянный)
P_k = B_{k−1} · i               (проценты на остаток)
A_k = D + P_k                   (платёж k-го месяца)
```

### 4.3. Общая переплата

```text
Переплата = Σ всех платежей − первоначальная сумма долгов
```

### 4.4. Алгоритм моделирования стратегии

Входные данные: список долгов, ежемесячный бюджет `M`, стратегия, список досрочных платежей.

```text
1. Если M < сумма минимальных платежей → ошибка.
2. Пока есть долги с остатком > 0 (и месяц < 600):
   2.1. Начислить проценты на остаток каждого долга: B = B + B · i.
   2.2. Свободная сумма = M.
   2.3. Выплатить минимальный платёж по каждому долгу (не больше остатка); вычесть из свободной суммы.
   2.4. Добавить досрочные платежи, запланированные на этот месяц.
   2.5. Упорядочить долги с остатком по правилу стратегии:
        Лавина → по убыванию ставки; Снежный ком → по возрастанию остатка.
   2.6. Направлять свободную сумму на первый долг в списке, затем на следующий и т.д.
   2.7. Записать строку графика (месяц, платёж, проценты, основной долг, остаток).
3. Вернуть срок (число месяцев), сумму выплат и сумму процентов.
```

Для базовой стратегии шаги 2.5–2.6 не выполняются, освободившиеся платежи не перераспределяются.

### 4.5. Досрочное погашение

| Эффект | Правило |
|--------|---------|
| Сократить срок | Платёж остаётся прежним, остаток уменьшается быстрее, долг закрывается раньше |
| Снизить платёж | Срок остаётся прежним, платёж пересчитывается по формуле 4.1 для нового остатка и оставшегося срока |

### 4.6. Правила валидации

| Поле | Правило |
|------|---------|
| Остаток | > 0 |
| Ставка | от 0 до 100 % |
| Мин. платёж | > 0; должен покрывать начисленные за месяц проценты, иначе долг не погашается |
| Бюджет | не меньше суммы мин. платежей |
| Досрочный платёж | > 0, не больше остатка на момент платежа |

### 4.7. Контрольный пример

**Исходные данные**

| Долг | Остаток, ₽ | Ставка, % | Мин. платёж, ₽ |
|------|-----------:|----------:|---------------:|
| Кредитная карта | 60 000 | 29,9 | 3 000 |
| Потребительский кредит | 200 000 | 15,0 | 7 000 |
| Рассрочка на телефон | 30 000 | 0,0 | 3 000 |

Итого долг: 290 000 ₽; сумма минимальных платежей: 13 000 ₽/мес.

**Результаты (расчёт по алгоритму 4.4)**

| Сценарий | Бюджет, ₽/мес | Срок, мес. | Всего выплат, ₽ | Переплата, ₽ |
|----------|--------------:|-----------:|----------------:|-------------:|
| Базовая (только мин. платежи) | 13 000 | 36 | 363 066,92 | 73 066,92 |
| Снежный ком | 20 000 | 17 | 325 953,80 | 35 953,80 |
| Лавина | 20 000 | 17 | 323 002,56 | 33 002,56 |
| Лавина + досрочно 5 000 ₽/мес | 25 000 | 13 | 315 287,07 | 25 287,07 |

**Выводы:** «Лавина» дешевле «Снежного кома» на 2 951,24 ₽ и дешевле базового варианта на 40 064,36 ₽; дополнительные 5 000 ₽/мес сокращают срок на 4 месяца и экономят ещё 7 715,49 ₽.

Все маршруты, кроме регистрации и входа, требуют заголовок `Authorization: Bearer <токен>`. Ошибки возвращаются в виде `{"detail": "понятное сообщение"}`, ошибки валидации полей — дополнительно в `errors: [{field, message}]`.

**Правила расчёта, уточнённые при реализации**

- Стратегии (п. 4.4) считают проценты без промежуточного округления, до копеек округляются строки графика и итоги — так получаются значения контрольного примера 4.7. График одного долга (п. 4.1, 4.2) округляет проценты каждый месяц, а последний платёж закрывает остаток, поэтому сумма основного долга точно равна исходному остатку (T3).
- «Снизить платёж» для плана из нескольких долгов: подбирается наименьший ежемесячный бюджет (с точностью до копейки), при котором срок и переплата не больше, чем без досрочного платежа (критерий приёмки 4).
- Досрочный платёж без указанного долга добавляется к свободной сумме и распределяется по правилу стратегии; для базовой стратегии — на долг с наибольшей ставкой.
