# Неделя 2 — отчёт о проделанной работе

**Проект:** DebtFree — веб-приложение для планирования погашения долгов
**Этап:** базовая часть backend и frontend

На этой неделе подготовлена основа приложения: структура проектов, база данных, авторизация и учёт долгов. Frontend подключён к API.

---

## Backend

**Стек:** Python, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL 16, Pydantic

Что сделано:

- **Структура проекта:** код разделён на слои `api` (маршруты), `services` (бизнес-логика), `models` (таблицы БД), `schemas` (валидация данных) и `core` (расчёты).
- **Конфигурация:** настройки читаются из переменных окружения (`.env`) через pydantic-settings, рядом лежит шаблон `.env.example`.
- **База данных:** по ER-диаграмме описаны модели `users`, `debts`, `strategies`, `scenarios`, `payment_schedule`, `extra_payments`. Создана первая миграция Alembic (`0001_initial_schema`).
- **Авторизация:**
  - регистрация и вход по email и паролю;
  - пароли хешируются через bcrypt;
  - после входа выдаётся JWT-токен.

  Эндпоинты: `/auth/register`, `/auth/login`, `/auth/me`.
- **Учёт долгов (CRUD):** `GET/POST /debts`, `GET/PUT/DELETE /debts/{id}`. Каждый пользователь видит только свои долги.
- **Валидация:** остаток долга > 0, ставка от 0 до 100 %, минимальный платёж должен покрывать проценты. Ошибки возвращаются в едином формате.
- **Расчёты:** начат модуль `calculator`: формулы аннуитетного и дифференцированного платежа.
- **Тесты:** первые unit-тесты на схемы, авторизацию и формулы платежей.

---

## Frontend

**Стек:** React 18, Vite, React Router

Что сделано:

- **Проект:** создан через Vite, в dev-режиме настроено проксирование запросов `/api` на backend.
- **Маршрутизация:** заведены основные страницы приложения (`/debts`, `/compare`, `/plan`, `/scenarios`). Страницы без входа недоступны: неавторизованный пользователь перенаправляется на вход.
- **Страница входа и регистрации:** формы с проверкой полей и выводом ошибок от сервера.
- **API-клиент (`api.js`):** общие функции запросов, токен в заголовке `Authorization`, обработка ошибок.
- **Контекст пользователя:** данные о текущем пользователе и токен доступны всем страницам.
- **Учёт долгов:**
  - список долгов с общей суммой и суммой минимальных платежей;
  - форма добавления и редактирования;
  - удаление с подтверждением.
- **Оформление:** общие стили и базовые UI-компоненты (кнопки, поля ввода, таблицы), вёрстка по макету.
