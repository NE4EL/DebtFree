# Неделя 3 — итоговый отчёт

**Проект:** DebtFree — веб-приложение для планирования погашения долгов
**Статус:** проект полностью реализован, упакован в Docker и готов к запуску

На этой неделе завершена разработка: frontend и backend доведены до рабочего состояния, связаны между собой, покрыты тестами и упакованы в Docker. Отчёт подводит итог по всему проекту.

---

## Backend

**Стек:** Python, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL 16, Pydantic, JWT (PyJWT), bcrypt

Что сделано:

- **Авторизация:** регистрация, вход и получение текущего пользователя. Пароли хранятся в виде bcrypt-хешей, доступ к API защищён JWT-токеном.
- **Учёт долгов (CRUD):** добавление, просмотр, изменение и удаление долгов. Данные проверяются: остаток > 0, ставка от 0 до 100 %, минимальный платёж покрывает проценты.
- **Расчётное ядро** (`app/core`):
  - аннуитетный и дифференцированный платёж, помесячный график (платёж, основной долг, проценты, остаток);
  - стратегии погашения «Лавина», «Снежный ком» и «Только минимальные платежи», их сравнение по переплате и сроку;
  - досрочное погашение, разовое или регулярное, в режимах «сократить срок» и «снизить платёж».
- **Сценарии:** сохранение расчётов, их просмотр и удаление.
- **База данных:** таблицы `users`, `debts`, `strategies`, `scenarios`, `payment_schedule`, `extra_payments`. Схема создаётся миграцией Alembic, миграции применяются автоматически при старте.
- **API:** 15 эндпоинтов в группах `auth`, `debts`, `calculations`, `scenarios`. Swagger-документация доступна по `/docs`.
- **Тесты (pytest):** 109 тестов. Покрыты расчёты, стратегии, схемы, авторизация, API и интеграция с БД. Есть property-based тесты.

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | `/auth/register`, `/auth/login` | Регистрация, вход |
| GET | `/auth/me` | Текущий пользователь |
| GET, POST | `/debts` | Список долгов с итогами, добавление долга |
| GET, PUT, DELETE | `/debts/{id}` | Просмотр, изменение, удаление долга |
| POST | `/schedule` | График платежей |
| POST | `/compare` | Сравнение стратегий |
| POST | `/early-payment` | Расчёт досрочного погашения |
| GET, POST | `/scenarios` | Список сценариев, сохранение сценария |
| GET, DELETE | `/scenarios/{id}` | Просмотр, удаление сценария |

## Frontend

**Стек:** React 18, Vite, React Router, Chart.js (react-chartjs-2), Vitest, nginx

Что сделано:

- **Страницы:**
  - вход и регистрация;
  - список долгов с общей суммой и суммой минимальных платежей;
  - форма добавления и редактирования долга;
  - график погашения отдельного долга (таблица и диаграмма остатка);
  - сравнение стратегий по заданному бюджету;
  - план с досрочным погашением;
  - сохранённые сценарии и просмотр сценария.
- **Компоненты:** формы, таблицы, графики Chart.js и общие UI-элементы.
- **Работа с API:** единый клиент (`api.js`), хранение токена, обработка ошибок от backend. Данные пользователя доступны через React Context.
- **Форматирование:** суммы, проценты и сроки выводятся в удобном виде (`format.js`).
- **Тесты (Vitest):** 17 тестов на API-клиент и форматирование.
- **Сборка:** production-сборку Vite отдаёт nginx. Он же проксирует запросы `/api` в backend, поэтому всё приложение открывается по одному адресу.

---

## Инфраструктура

- `docker-compose.yml` поднимает три контейнера: `db` (PostgreSQL), `backend` (FastAPI) и `frontend` (nginx + React).
- Backend-тесты запускаются отдельным профилем: `docker compose --profile test run --rm tests`.
- Инструкция по запуску на другом компьютере лежит в `DEPLOY.md`. Приложение открывается по адресу `http://localhost:8080`.
